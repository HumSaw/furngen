# FurnGen v2.1 — процедурный генератор мебели

Система для 3ds Max + Corona Renderer. Генерирует production-ready мебель уровня интерьерных каталогов в едином стиле и палитре:

- **Диваны** (6 типов): прямой, угловой, модульный, loveseat, chaise, кресло — плюс опциональный декор: плед через подлокотник и акцентные подушки
- **Кровати** (4 типа): односпальная, двуспальная, king-size, с балдахином — матрас, изголовье, драпированное одеяло, подушки
- **Стулья** (4 типа): обеденный, барный (с подножкой-кольцом), лаунж-кресло, табурет
- **Столы** (5 типов): обеденный (с царгой), кофейный круглый, приставной, письменный (с тумбой и ящиками), тумбочка
- **Хранение** (2 типа): двухдверный шкаф с ручками-рейлингами, комод на 3 ящика с латунными ручками
- **Декор** (7 типов): пуф, ковёр, торшер, книжный шкаф со случайно расставленными книгами, ТВ-тумба, растение в кашпо, напольное зеркало
- **BUILD LIVING ROOM** — гостиная одной кнопкой: диван + ковёр + кофейный столик + лаунж-кресло + пуф + торшер + приставной столик + книжный шкаф + растение
- **BUILD BEDROOM** — спальня одной кнопкой: кровать + 2 тумбочки + комод + шкаф + ковёр + скамья + зеркало + растение

8 стилей, 5 тканей, сидированная уникальность каждой генерации.

## Установка и запуск

1. Скопируйте папку `sofa-generator` на диск.
2. В 3ds Max: **Scripting → Run Script → `SofaGenerator.ms`**
3. Откроется панель генератора: настройте параметры и нажмите **GENERATE SOFA**.

Рекомендуемые единицы сцены: **сантиметры** (Customize → Units Setup → System Unit = 1 cm).

## Почему MaxScript (выбор стека)

- Нативный доступ к сцене, модификаторам и материалам без зависимостей — скрипт запускается на любой машине с Max.
- Python в 3ds Max всё равно обращается к MaxScript API через `pymxs`, добавляя прослойку и хрупкость между версиями.
- Corona-материалы (`CoronaPhysicalMtl`) создаются напрямую; при отсутствии Corona автоматический fallback на Physical Material.

## Архитектура (модули)

| Файл | Ответственность |
|---|---|
| `SofaGenerator.ms` | Загрузчик: подключает модули, открывает UI |
| `SofaGen_Core.ms` | Конфиг (`SofaConfig`), RNG, утилиты, стилевые пресеты |
| `SofaGen_Geometry.ms` | Построители частей: мягкие блоки, подушки, подлокотники, ножки, кант |
| `SofaGen_Materials.ms` | Corona-материалы тканей (velvet/linen/boucle/cotton/leather), ножек, канта |
| `SofaGen_Assembly.ms` | Сборка дивана по типам: прямой, угловой, модульный, loveseat, chaise, кресло |
| `SofaGen_Furniture.ms` | Кровати, стулья, столы, декор, Room Set — переиспользуют Core/Geometry/Materials |
| `SofaGen_QA.ms` | Автопроверка: геометрия, материалы, масштаб, именование |
| `SofaGen_UI.ms` | Панель: категория → тип, Generate, Randomize / Random ALL, Room Set, пресеты (INI) |

## Пайплайн реализма (без «пластикового» вида)

1. **ChamferBox** с большим fillet — базовая скруглённая форма.
2. **Push** — надувание вдоль нормалей: эффект наполнителя, распирающего чехол.
3. **Noise (fractal) ×2** — крупные складки провисания + мелкие морщины ткани.
4. **TurboSmooth** — subdivision (1–3 итерации по уровню качества).
5. **Сидированный jitter** позиций, наклонов подушек и seed каждого Noise — каждая генерация уникальна и не «игрушечно» симметрична.
6. **Кант** — renderable-сплайн по периметру подушки, материал чуть темнее ткани (читается как шов).
7. **Материалы**: roughness + sheen (ворс velvet), fractal-noise bump (переплетение ткани), cellular bump (зерно кожи), лёгкая транслюцентность тонких тканей.

## Уровни качества

- **Draft** — быстрые прокси для блокинга сцены.
- **Production** — интерьерные рендеры общих планов.
- **Close-up 4K** — плотная сегментация + TurboSmooth ×3 для крупных планов.

## Ограничения (честно, как senior TA)

- Складки ткани аппроксимированы модификаторами — для hero-close-up уровня Marvelous Designer нужен реальный cloth-sim (Max Cloth modifier или MD с последующим импортом). Система спроектирована так, что подушку легко заменить симулированным мешем.
- Строчка швов реализована через bump/кант; для экстремальных макро-планов добавьте displacement-карту стежков в слот displacement CoronaPhysicalMtl.
- Имена свойств Corona отличаются между версиями — все установки защищены (`sgSetFirst`), скрипт не падает ни на одной версии.

## Расширение системы (кресла, кровати, столы)

Core / Geometry / Materials / QA — общие. Для нового предмета мебели создаётся только новый Assembly-модуль:

```maxscript
-- BedGen_Assembly.ms
fn sgBuildBed cfg = (
    -- переиспользуем sgSoftBlock, sgCushion, sgLeg, sgMakeFabricMtl...
)
```

`SofaConfig` расширяется полями нового предмета либо наследуется отдельным структом.
