# Быстрый старт

Установка FurnGen и первая сгенерированная модель.

---

## 1. Требования

| Компонент | Требование |
| --- | --- |
| 3ds Max | 2020 или новее |
| Системные единицы | Сантиметры |
| Corona Renderer | Необязательно (см. раздел [Материалы](#4-материалы-и-рендер)) |

---

## 2. Установка

### Из релизного архива

1. Скачайте `FurnGen-<версия>.zip` со страницы Releases.
2. Распакуйте в любую папку, например `C:\Scripts\FurnGen\`.
3. Убедитесь, что структура сохранилась:

```
FurnGen/
├── FurnGen.ms          <- точка входа
└── modules/
    ├── core.ms
    ├── geometry.ms
    ├── materials.ms
    ├── sofa.ms
    ├── furniture.ms
    ├── qa.ms
    └── ui.ms
```

> **Важно.** `FurnGen.ms` находит модули относительно собственного пути.
> Папку `modules` нельзя переименовывать или отделять от точки входа.

### Из исходников

```bash
git clone https://github.com/OWNER/furngen.git
```

Запускать можно прямо из `src/FurnGen.ms` — сборка не требуется.

---

## 3. Настройка единиц измерения

Вся геометрия рассчитана в сантиметрах. Перед первым запуском:

1. `Customize → Units Setup…`
2. Кнопка **System Unit Setup**
3. `1 Unit = 1.0 Centimeters`
4. В разделе Display Unit Scale выберите **Metric → Centimeters**

Если единицы отличаются, FurnGen не откажется работать, но выведет
предупреждение в строке состояния: модели окажутся в неверном масштабе
относительно остальной сцены.

---

## 4. Материалы и рендер

FurnGen подбирает тип материала автоматически:

| Условие | Используемый материал |
| --- | --- |
| Corona установлена **и назначена активным рендером** | `CoronaPhysicalMtl` |
| Любой другой активный рендер | `PhysicalMaterial` |
| Свойство цвета недоступно | `StandardMaterial` |

Это важное различие: Corona-материалы рендерятся серыми или чёрными в чужом
движке, поэтому проверяется не только наличие плагина, но и активный рендер.
Если модели получились серыми — см. [Решение проблем](./troubleshooting.md).

---

## 5. Запуск

1. В 3ds Max: `Scripting → Run Script…`
2. Выберите `FurnGen.ms`
3. Откроется панель **FurnGen**

В окне MAXScript Listener появится отчёт о загрузке:

```
FurnGen Core 1.0.0 loaded
FurnGen Materials loaded (Corona available: false, Corona active: false)
FurnGen 1.0.0 ready. Recommended System Units: Centimeters.
```

Вторая строка — самая полезная: она сразу показывает, будет ли использован
Corona-стек. Corona-материалы применяются только когда плагин установлен
**и** активен, то есть когда оба значения равны `true`.

Кроме этого при успешной загрузке автоматически регистрируется макрос —
см. раздел [Кнопка на панели инструментов](#7-кнопка-на-панели-инструментов).

---

## 6. Первая генерация

1. **Category:** `Sofas`
2. **Style:** `Scandinavian`
3. **Fabric:** `Boucle`
4. Нажмите **GENERATE**

Диван появится в сцене, камера приблизится к нему, а в строке состояния
внизу панели выведется результат автопроверки — например `OK: 14 parts`.

Дальше нажимайте **Surprise me** — кнопка рандомизирует категорию, тип,
стиль, ткань и габариты, показывая возможности системы за несколько секунд.

---

## 7. Кнопка на панели инструментов

Запускать скрипт через меню каждый раз неудобно. Ничего настраивать не нужно:
при успешной загрузке `FurnGen.ms` сам регистрирует макрос.

1. `Customize → Customize User Interface → Toolbars`
2. Категория — **FurnGen**
3. Перетащите **FurnGen** на любую панель

Кнопка сохраняется между сеансами. Нажатие повторно выполняет загрузчик по
тому пути, откуда вы запустили его первый раз, — поэтому папку после этого
лучше не перемещать.

Регистрация обёрнута в `try`, поэтому если конфигурация Max её запрещает,
инструмент всё равно загрузится и выведет:

```
FurnGen: macro registration skipped (...)
```
