## Раздел «What to build»

### Category

Семейство мебели. При смене категории список **Type** перестраивается,
а неприменимые параметры блокируются — панель всегда показывает только то,
что реально влияет на результат.

| Категория | Типы |
| --- | --- |
| Sofas | Straight, Corner / L-shape, Modular, Loveseat, Chaise lounge, Armchair |
| Beds | Single, Double, King size, Canopy |
| Chairs | Dining chair, Bar stool, Lounge chair, Stool |
| Tables | Dining table, Coffee table, Side table, Desk, Nightstand |
| Storage | Wardrobe, Dresser |
| Decor | Pouf, Rug, Floor lamp, Bookshelf, TV console, Plant, Mirror |

### Style

Восемь стилей. Стиль задаёт не только палитру, но и пропорции, форму
подлокотников и тип ножек — то есть влияет на геометрию, а не только на цвет.

| Стиль | Подлокотники | Ножки | Палитра | Переопределяет |
| --- | --- | --- | --- | --- |
| Modern | square, 20 см | block, 8 см | холодные серые | — |
| Minimal | square, 14 см | none, 4 см | белые и off-white | piping → off |
| Scandinavian | rounded, 18 см | cone, 16 см | светлые нейтральные, шалфей | — |
| Japandi | square, 16 см | block, 10 см | приглушённые земляные | height → 74 см |
| Luxury | rounded, 26 см | cylinder, 10 см | изумруд, кобальт, латунь | fabric → velvet |
| Classic | rounded, 28 см | cone, 12 см | тёплые коричневые | piping → on |
| Brutalism | square, 30 см | none, 2 см | бетонные серые | piping → off, softness → 0.35 |
| Mid-century | pillow, 18 см | cone, 18 см | охра, бирюза, орех | — |

Стиль может **переопределить** ваш выбор в других разделах панели: Luxury
принудительно ставит велюр, Minimal и Brutalism отключают кант. Это сделано
намеренно — пресет представляет цельный дизайнерский язык.

Три силуэта подлокотника:

| Значение | Форма |
| --- | --- |
| `square` | Прямая плита, узкий fillet 14 %, минимальное надувание |
| `rounded` | Крупный fillet 42 %, мягкое надувание |
| `pillow` | Низкий каркас с отдельным валиком-подушкой сверху |

`pillow` — единственный вариант из двух объектов: валик становится дочерней
нодой подлокотника, поэтому автопроверка обходит иерархию рекурсивно.

### Fabric

| Ткань | Особенности шейдинга |
| --- | --- |
| Boucle | Крупное зерно, высокая шероховатость |
| Velvet | Выраженный sheen, мягкий блик под углом |
| Linen | Заметное плетение, матовая поверхность |
| Cotton | Ровная гладкая поверхность |
| Leather | Клеточный рисунок пор, низкая шероховатость |

## Раздел «Dimensions (cm)»

Активен только для категории **Sofas** — у остальных предметов габариты
заданы типом (двуспальная кровать не может быть шириной 90 см).

| Параметр | Диапазон | Назначение |
| --- | --- | --- |
| Seats | 1–6 | Число посадочных мест; влияет на минимальную ширину |
| Width | 40–500 | Общая ширина |
| Depth | 30–220 | Глубина |
| Height | 30–250 | Полная высота вместе со спинкой |

## Раздел «Upholstery»

| Параметр | Действие |
| --- | --- |
| Softness `0.0–1.0` | Сила «надувания» и глубина складок. `0.2` — подтянутая обивка, `0.8` — глубокая мягкая посадка |
| Piping seams | Кант по периметру подушек (renderable-сплайн) |
| Back cushions | Отдельные подушки спинки вместо цельной панели |
| Styling | Плед через подлокотник и две акцентные подушки |

Блокировка по категориям: `Softness` и `Piping` доступны для диванов,
кроватей и стульев; `Back cushions` и `Styling` — только для диванов.

## Раздел «Generate»

### Quality

| Уровень | Сегменты | Fillet | TurboSmooth | Мелкие морщины |
| --- | --- | --- | --- | --- |
| Draft | 3 | 2 | 1 | нет |
| Production | 5 | 3 | 2 | да |
| Close-up 4K | 8 | 4 | 3 | да |

Мелкий проход Noise отключён **только** в Draft — именно это делает его
достаточно быстрым для перебора кнопкой **Randomize**. Close-up 4K не добавляет
новых эффектов по сравнению с Production, а лишь повышает плотность сетки,
поэтому берите его только когда мебель занимает основную часть кадра.

Рабочий приём: перебирайте варианты в **Draft**, а найденный удачный
`Seed` перегенерируйте в **Production**.

### Seed

Число, определяющее все случайные величины: наклоны подушек, seed каждого
модификатора Noise, выбор оттенка из палитры стиля. **Один и тот же Seed при
тех же параметрах всегда даёт идентичную модель** — запишите число, если
вариант понравился.

### Кнопки

| Кнопка | Действие |
| --- | --- |
| **GENERATE** | Строит предмет по текущим параметрам |
| **Randomize** | Рандомизирует параметры внутри текущей категории и генерирует |
| **Surprise me** | Рандомизирует всё, включая категорию |
| **BUILD LIVING ROOM** | Гостиная целиком: диван, ковёр, кофейный столик, лаунж-кресло, пуф, торшер, приставной столик, книжный шкаф, растение |
| **BUILD BEDROOM** | Спальня целиком: кровать, две тумбочки, комод, шкаф, ковёр, скамья, зеркало, растение |
| **Delete last** | Удаляет последний созданный объект |

Комнаты собираются в едином стиле и палитре: базовый `Seed` смещается для
каждого предмета, поэтому вещи различаются между собой, но остаются одним
комплектом.

## Раздел «Presets»

Наборы параметров сохраняются в INI-файл в папке пользовательских скриптов
3ds Max (`getDir #userScripts`).

- **Save** — записывает текущее состояние панели под введённым именем
- **Load** — восстанавливает набор, включая категорию и тип

## Строка состояния

Нижняя строка панели показывает результат последней операции:

| Сообщение | Значение |
| --- | --- |
| `OK: 34 parts / 118240 tris, render ready` | Успех, замечаний нет |
| `CHECKED: 34 parts / 118240 tris, 2 issue(s) - see Listener` | Модель создана, но есть замечания |
| `Error: ...` | Сбой; частичная геометрия откачена автоматически |

Сами замечания печатаются в Listener:

| Строка | Значение |
| --- | --- |
| `WARN: system units are Inches, Centimeters recommended` | Исправьте единицы и сгенерируйте заново |
| `WARN: implausible width: N cm` | Ширина вне диапазона 20–650 см |
| `WARN: implausible height: N cm` | Высота вне диапазона 1–260 см |
| `WARN: default node name: Box001` | Деталь осталась без имени — сообщите об этом |
| `FAIL: missing material: NAME` | Баг: приложите `Seed` к issue |
| `FAIL: empty geometry: NAME` | Деталь выродилась; приложите `Seed` |
| `FAIL: nothing was created` | Сборщик не вернул группу |

Различие `OK` и `CHECKED` важно: в обоих случаях геометрия есть, но только
`OK` означает, что смотреть ничего не нужно.

## Структура сцены

Все объекты попадают на слой **FurnGen_Furniture** и группируются с
осмысленным именем, например `Sofa_scandinavian_straight`. Детали внутри
группы названы по назначению: `Sofa_Base`, `Sofa_SeatCushion_1`,
`Bed_Duvet`, `Plant_Leaf_003`.

Вместе со слоем и группировкой это означает, что модель можно сразу
экспортировать или переносить в основную сцену без ручной уборки.

## Рекомендуемый рабочий процесс

1. Выберите категорию и стиль
2. Качество — **Draft**
3. Нажимайте **Randomize**, пока не появится подходящий вариант
4. Запишите значение `Seed`
5. Переключите качество на **Production**
6. **GENERATE** — тот же предмет пересоберётся с полной детализацией
