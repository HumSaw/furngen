## Что генерирует система

| Категория | Типы |
| --- | --- |
| **Диваны** | Прямой, угловой, модульный, loveseat, chaise lounge, кресло |
| **Кровати** | Односпальная, двуспальная, king-size, с балдахином |
| **Стулья** | Обеденный, барный, лаунж-кресло, табурет |
| **Столы** | Обеденный, кофейный, приставной, письменный, тумбочка |
| **Хранение** | Двухдверный шкаф, комод на три ящика |
| **Декор** | Пуф, ковёр, торшер, книжный шкаф, ТВ-тумба, растение, зеркало |
| **Комнаты** | Гостиная и спальня целиком, одной кнопкой |

Каждый предмет строится в одном из **8 стилей** с одной из **5 тканей**, а число `Seed`
гарантирует, что одна и та же комбинация параметров всегда даёт идентичный результат.

## Требования

- **3ds Max 2020** или новее
- **Системные единицы = сантиметры** (`Customize → Units Setup → System Unit Setup`)
- **Corona Renderer** — необязательно. Без него материалы автоматически
  собираются на `PhysicalMaterial`, и модели остаются пригодными для рендера.

---

## Быстрый путь

1. Скачайте `FurnGen-<версия>.zip` из раздела Releases и распакуйте.
2. В 3ds Max: `Scripting → Run Script…` → выберите `FurnGen.ms`.
3. Нажмите **GENERATE**.

Подробности — в [Быстром старте](./getting-started.md).
